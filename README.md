# TCR Prediction

**Description:**
Our main objective of the project is to train a machine learning model using supervised learning techniques that will be able to predict whether or not a TCR alpha, TCR beta, peptide, and HLA/MHC Class I complex combination binds well enough to incur an immunogenic response. The peptides are oncogenic antigens that are associated with cancer, so if we can train the model to detect characteristics of good binding from structural data, we can test different TCR alpha and TCR beta combinations for known oncogenic antigens that are being presented by the MHCI and find candidate TCRs for personalized cancer treatment.
